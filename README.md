# 🌤️ Gemini Weather + Travel Guide  
### Live Weather • AI-Generated Travel Suggestions • Streamlit • WeatherAPI • Google Gemini  

This project is a beautiful, interactive Streamlit web app that combines **real-time weather data** with **AI-powered travel insights** using **Google Gemini (via LangChain)**.

Users simply enter a city name →  
✅ WeatherAPI fetches current weather  
✅ Gemini generates top travel attractions based on the weather  
✅ The app displays a clean UI with maps, tabs, stats, and more.

## 🌟 Features

### ✅ **Real-time Weather (WeatherAPI)**
- Temperature, humidity, wind, pressure  
- Weather condition icon  
- Local time, UV index, visibility  
- Raw JSON explorer (for developers)

### ✅ **AI-Powered Travel Guide (Google Gemini)**
- Top 10 attractions tailored to current weather  
- Short, concise descriptions  
- Weather-based recommendations (indoor/outdoor suitability)

### ✅ **Modern UI / UX**
- Gradient header  
- Beautiful stat cards  
- Tabs: Weather • Attractions • Map • Raw Data  
- Responsive layout  
- Clean typography and emojis

### ✅ **Tech Stack**
- **Python 3.10+**  
- **Streamlit**  
- **WeatherAPI**  
- **Google Gemini (LangChain + langchain-google-genai)**  
- **Requests**, **Map rendering**, **Custom CSS**
